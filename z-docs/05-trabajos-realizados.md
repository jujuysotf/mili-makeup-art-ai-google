# Trabajos realizados de ejemplo

Portfolio armado con el material de `z-docs/material-exclusivo`. Los títulos, la categoría y el texto son de ejemplo: la dueña puede cambiarlos sin mover los archivos.

Categorías usadas: `social`, `novia`, `artístico`, `quince`, `sesión`, `proceso`.

La ruta de cada archivo es relativa a `z-docs/material-exclusivo/`.

## Cómo corregirlo

En cada trabajo se puede cambiar:

- `titulo`
- `categoria`
- `texto`
- qué archivo es la foto principal
- si el trabajo se publica o no (`publicar: si` / `publicar: no`)
